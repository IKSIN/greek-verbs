# Greek Verbs PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA на GitHub Pages для изучения 200 греческих глаголов A2 в обоих направлениях (EL→RU, RU→EL) с SRS-карточками, режимом ввода, фильтрами и общим словарём, пополняемым через GitHub API.

**Architecture:** Svelte 5 SPA без бэкенда. Вся логика — чистые TS-модули в `src/lib` (SRS, проверка ответа, фильтры, сессия, хранилища, GitHub-репозиторий словаря) с Vitest-тестами; экраны в `src/screens` вызывают единый модуль состояния `src/lib/app.svelte.ts`. Словарь — `data/words.json` в репо, читается/пишется через GitHub Contents API; прогресс — IndexedDB на устройстве.

**Tech Stack:** Vite, Svelte 5 (runes), TypeScript, vite-plugin-pwa, idb, Vitest, fake-indexeddb, @vite-pwa/assets-generator, GitHub Actions + Pages.

**Spec:** `docs/superpowers/specs/2026-10-10-greek-pwa-design.md`

**Отклонения от спеки (осознанные):** валидатор словаря — модуль `src/lib/validate.ts` + тест `tests/words.test.ts` вместо отдельного `scripts/validate-words.ts` (запускается тем же `npm test` в CI); кнопка ударения реализована функцией `src/lib/accent.ts` внутри `TypeAnswer.svelte`, без отдельного компонента `AccentKey`.

## Global Constraints

- Язык интерфейса — русский; греческий текст всегда с ударениями (монотоника).
- Svelte 5 runes (`$state`, `$derived`, `$props`), TypeScript strict.
- Словарь: путь `data/words.json`, ветка `main`; формат JSON — `JSON.stringify(words, null, 2) + '\n'`.
- Ключ прогресса: `` `${wordId}:${direction}` ``, `direction` ∈ `el-ru | ru-el`.
- Ключи localStorage с префиксом `greek.`: `greek.settings`, `greek.newSeen`, `greek.pending`, `greek.version`.
- SRS: старт ease 2.5, минимум 1.3; «выучено» — интервал ≥ 21; «трудное» — ≥ 3 `again` среди последних 5 оценок.
- Лимит новых слов по умолчанию 10 в день на направление.
- GitHub-запись: до 3 попыток при 409/422.
- `base` сборки берётся из `BASE_PATH` (в CI — `/<repo>/`), локально `/`.
- Node 22 в CI.
- Никаких сторонних сервисов, кроме GitHub API.

## Review Focus

1. Импорт чужого или битого файла прогресса → ошибка-тост, существующий прогресс не тронут (тест в Task 6).
2. Оба пользователя одновременно добавляют одно и то же слово (одинаковый `id`) → второе сохраняется с суффиксом `-2`, ничьё слово не теряется (тест в Task 8).
3. Греческий и русский текст при base64-кодировании для GitHub API не искажается (тест в Task 8).
4. Пустой, пробельный или латинский ввод в режиме «Ввод» → `wrong`, без падений и ложного `correct` (тест в Task 2).
5. Наступил новый день → счётчик новых слов обнулился; повреждённый localStorage → настройки по умолчанию, а не падение (тест в Task 5).

```ts
export function todayISO(d: Date = new Date()): string {
  const y = d.getFullYear();
  const m = String(d.getMonth() + 1).padStart(2, '0');
  const day = String(d.getDate()).padStart(2, '0');
  return `${y}-${m}-${day}`;
}

export function addDays(iso: string, n: number): string {
  const [y, m, d] = iso.split('-').map(Number);
  return new Date(Date.UTC(y, m - 1, d + n)).toISOString().slice(0, 10);
}
```

`src/lib/srs.ts`:

```ts
import type { CardState, Direction, Grade } from './types';
import { addDays } from './date';

export const START_EASE = 2.5;
export const MIN_EASE = 1.3;

export function newCard(wordId: string, direction: Direction, today: string): CardState {
  return { wordId, direction, interval: 0, ease: START_EASE, due: today, reps: 0, lapses: 0, recent: [] };
}

const round2 = (x: number) => Math.round(x * 100) / 100;

export function schedule(s: CardState, grade: Grade, today: string): CardState {
  let { interval, ease, reps, lapses } = s;
  if (grade === 'again') {
    reps = 0;
    interval = 1;
    ease -= 0.2;
    lapses += 1;
  } else if (grade === 'hard') {
    interval = Math.max(1, Math.round(interval * 1.2));
    ease -= 0.15;
  } else {
    const base = reps === 0 ? 1 : reps === 1 ? 3 : Math.round(interval * ease);
    interval = grade === 'easy' ? Math.max(1, Math.round(base * 1.3)) : base;
    if (grade === 'easy') ease += 0.15;
    reps += 1;
  }
  ease = Math.max(MIN_EASE, round2(ease));
  return {
    ...s,
    interval,
    ease,
    reps,
    lapses,
    due: addDays(today, interval),
    recent: [...s.recent, grade].slice(-5),
  };
}
```

`src/lib/answer.ts`:

```ts
export type AnswerResult = 'correct' | 'accent' | 'wrong';

export function stripAccents(s: string): string {
  return s.normalize('NFD').replace(/[̀-ͯ]/g, '').normalize('NFC');
}

export function normalize(s: string): string {
  return s
    .normalize('NFC')
    .trim()
    .replace(/\s+/g, ' ')
    .toLocaleLowerCase('el')
    .replace(/σ(?=$|[\s.,!?;:])/g, 'ς');
}

export function checkAnswer(input: string, expected: string): AnswerResult {
  const a = normalize(input);
  const b = normalize(expected);
  if (!a) return 'wrong';
  if (a === b) return 'correct';
  if (stripAccents(a) === stripAccents(b)) return 'accent';
  return 'wrong';
}
```

`src/lib/accent.ts`:

```ts
const TONOS: Record<string, string> = {
  α: 'ά', ε: 'έ', η: 'ή', ι: 'ί', ο: 'ό', υ: 'ύ', ω: 'ώ',
  Α: 'Ά', Ε: 'Έ', Η: 'Ή', Ι: 'Ί', Ο: 'Ό', Υ: 'Ύ', Ω: 'Ώ',
};
const PLAIN: Record<string, string> = Object.fromEntries(Object.entries(TONOS).map(([k, v]) => [v, k]));

/** Ставит/снимает тонос на последней гласной текущего слова перед курсором. */
export function toggleTonos(text: string, caret: number): string {
  for (let i = caret - 1; i >= 0; i--) {
    const ch = text[i];
    if (/\s/.test(ch)) break;
    const repl = TONOS[ch] ?? PLAIN[ch];
    if (repl) return text.slice(0, i) + repl + text.slice(i + 1);
  }
  return text;
}
```

```ts
import type { Conj, Direction, ProgressMap, Word } from './types';
import { progressKey } from './types';
import { stripAccents } from './answer';
import { isHard, statusOf, type Status } from './status';

export type StatusFilter = Status | 'hard';

export interface WordFilter {
  query: string;
  conj: Conj[];
  tags: string[];
  source: ('base' | 'user')[];
  addedBy: string[];
  status: StatusFilter[];
}

export const emptyFilter = (): WordFilter => ({ query: '', conj: [], tags: [], source: [], addedBy: [], status: [] });

export function isFilterActive(f: WordFilter): boolean {
  return !!f.query.trim() || [f.conj, f.tags, f.source, f.addedBy, f.status].some((g) => g.length > 0);
}

export const searchKey = (s: string): string => stripAccents(s.toLocaleLowerCase('el'));

export function applyFilter(words: Word[], f: WordFilter, progress: ProgressMap, dir: Direction): Word[] {
  const q = searchKey(f.query.trim());
  return words.filter((w) => {
    if (q && !searchKey(w.el).includes(q) && !searchKey(w.ru).includes(q)) return false;
    if (f.conj.length && !(w.conj && f.conj.includes(w.conj))) return false;
    if (f.tags.length && !w.tags.some((t) => f.tags.includes(t))) return false;
    if (f.source.length && !f.source.includes(w.source)) return false;
    if (f.addedBy.length && !(w.addedBy && f.addedBy.includes(w.addedBy))) return false;
    if (f.status.length) {
      const s = progress[progressKey(w.id, dir)];
      if (!f.status.some((st) => (st === 'hard' ? isHard(s) : statusOf(s) === st))) return false;
    }
    return true;
  });
}

const sortRu = (xs: Iterable<string>) => [...new Set(xs)].sort((a, b) => a.localeCompare(b, 'ru'));

export function facets(words: Word[]): { tags: string[]; authors: string[] } {
  return {
    tags: sortRu(words.flatMap((w) => w.tags)),
    authors: sortRu(words.flatMap((w) => (w.addedBy ? [w.addedBy] : []))),
  };
}
```

```ts
import type { Direction, Grade, ProgressMap, Word } from './types';
import { progressKey } from './types';

export interface SessionItem { word: Word; isNew: boolean }

export interface SessionState {
  queue: SessionItem[];
  requeued: string[];
  seen: string[];
  errors: number;
  total: number;
  answered: number;
}

export function shuffle<T>(xs: T[], rng: () => number = Math.random): T[] {
  const a = [...xs];
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}

function split(words: Word[], progress: ProgressMap, dir: Direction, today: string) {
  const due: Word[] = [];
  const fresh: Word[] = [];
  for (const w of words) {
    const s = progress[progressKey(w.id, dir)];
    if (!s) fresh.push(w);
    else if (s.due <= today) due.push(w);
  }
  return { due, fresh };
}

export function buildQueue(
  words: Word[], progress: ProgressMap, dir: Direction, today: string, newLimit: number,
  rng: () => number = Math.random,
): SessionItem[] {
  const { due, fresh } = split(words, progress, dir, today);
  return [
    ...shuffle(due, rng).map((word) => ({ word, isNew: false })),
    ...fresh.slice(0, Math.max(0, newLimit)).map((word) => ({ word, isNew: true })),
  ];
}

export function countDue(words: Word[], progress: ProgressMap, dir: Direction, today: string) {
  const { due, fresh } = split(words, progress, dir, today);
  return { due: due.length, fresh: fresh.length };
}

export function startSession(items: SessionItem[]): SessionState {
  return { queue: items, requeued: [], seen: [], errors: 0, total: items.length, answered: 0 };
}

export function answerSession(s: SessionState, grade: Grade): SessionState {
  const [head, ...rest] = s.queue;
  if (!head) return s;
  const id = head.word.id;
  const again = grade === 'again';
  const requeue = again && !s.requeued.includes(id);
  return {
    ...s,
    queue: requeue ? [...rest, { ...head, isNew: false }] : rest,
    requeued: requeue ? [...s.requeued, id] : s.requeued,
    seen: s.seen.includes(id) ? s.seen : [...s.seen, id],
    errors: s.errors + (again ? 1 : 0),
    answered: s.answered + 1,
  };
}
```

```ts
import type { Direction, KV } from './types';

export interface Settings { name: string; githubToken: string; newPerDay: number }

export const DEFAULT_SETTINGS: Settings = { name: '', githubToken: '', newPerDay: 10 };

const SETTINGS_KEY = 'greek.settings';
const NEW_SEEN_KEY = 'greek.newSeen';

export function readJSON<T>(storage: KV, key: string): T | null {
  try {
    const raw = storage.getItem(key);
    return raw ? (JSON.parse(raw) as T) : null;
  } catch {
    return null;
  }
}

export function loadSettings(storage: KV = localStorage): Settings {
  const raw = readJSON<Partial<Settings>>(storage, SETTINGS_KEY) ?? {};
  const n = Number(raw.newPerDay);
  return {
    name: typeof raw.name === 'string' ? raw.name : '',
    githubToken: typeof raw.githubToken === 'string' ? raw.githubToken : '',
    newPerDay: Number.isFinite(n) && n >= 0 ? Math.min(100, Math.floor(n)) : DEFAULT_SETTINGS.newPerDay,
  };
}

export function saveSettings(s: Settings, storage: KV = localStorage): void {
  storage.setItem(SETTINGS_KEY, JSON.stringify(s));
}

interface NewSeen { date: string; counts: Partial<Record<Direction, number>> }

export function newSeenToday(dir: Direction, today: string, storage: KV = localStorage): number {
  const r = readJSON<NewSeen>(storage, NEW_SEEN_KEY);
  return r && r.date === today ? (r.counts?.[dir] ?? 0) : 0;
}

export function incNewSeen(dir: Direction, today: string, storage: KV = localStorage): void {
  const r = readJSON<NewSeen>(storage, NEW_SEEN_KEY);
  const counts = r && r.date === today ? { ...r.counts } : {};
  counts[dir] = (counts[dir] ?? 0) + 1;
  storage.setItem(NEW_SEEN_KEY, JSON.stringify({ date: today, counts }));
}
```

```ts
import type { KV, WordChange } from './types';
import { readJSON } from './settings';

export interface PendingItem { change: WordChange; author: string }

const KEY = 'greek.pending';

export function loadPending(storage: KV = localStorage): PendingItem[] {
  const v = readJSON<unknown>(storage, KEY);
  return Array.isArray(v) ? (v as PendingItem[]) : [];
}

function savePending(items: PendingItem[], storage: KV): void {
  storage.setItem(KEY, JSON.stringify(items));
}

export function enqueuePending(item: PendingItem, storage: KV = localStorage): void {
  savePending([...loadPending(storage), item], storage);
}

export interface FlushResult { sent: number; remaining: number; error: unknown | null }

export async function flushPending(
  commit: (item: PendingItem) => Promise<void>,
  storage: KV = localStorage,
): Promise<FlushResult> {
  let items = loadPending(storage);
  let sent = 0;
  while (items.length) {
    try {
      await commit(items[0]);
    } catch (error) {
      return { sent, remaining: items.length, error };
    }
    items = items.slice(1);
    savePending(items, storage);
    sent++;
  }
  return { sent, remaining: 0, error: null };
}
```

```ts
import { openDB } from 'idb';
import type { CardState, ProgressMap } from './types';
import { progressKey } from './types';

export interface ProgressStore {
  getAll(): Promise<ProgressMap>;
  put(s: CardState): Promise<void>;
  deleteWord(wordId: string): Promise<void>;
  exportJSON(): Promise<string>;
  importJSON(json: string): Promise<number>;
  getCache<T>(key: string): Promise<T | undefined>;
  setCache(key: string, value: unknown): Promise<void>;
}

const DATE = /^\d{4}-\d{2}-\d{2}$/;

function isCardState(x: unknown): x is CardState {
  const c = x as CardState;
  return (
    !!c && typeof c === 'object' &&
    typeof c.wordId === 'string' && !!c.wordId &&
    (c.direction === 'el-ru' || c.direction === 'ru-el') &&
    [c.interval, c.ease, c.reps, c.lapses].every((v) => typeof v === 'number' && Number.isFinite(v)) &&
    typeof c.due === 'string' && DATE.test(c.due) &&
    Array.isArray(c.recent)
  );
}

export async function openProgressStore(name = 'greek'): Promise<ProgressStore> {
  const db = await openDB(name, 1, {
    upgrade(db) {
      db.createObjectStore('progress');
      db.createObjectStore('cache');
    },
  });

  return {
    async getAll() {
      const out: ProgressMap = {};
      for (const c of (await db.getAll('progress')) as CardState[]) out[progressKey(c.wordId, c.direction)] = c;
      return out;
    },
    async put(s) {
      await db.put('progress', s, progressKey(s.wordId, s.direction));
    },
    async deleteWord(wordId) {
      const tx = db.transaction('progress', 'readwrite');
      await Promise.all([
        tx.store.delete(progressKey(wordId, 'el-ru')),
        tx.store.delete(progressKey(wordId, 'ru-el')),
        tx.done,
      ]);
    },
    async exportJSON() {
      const cards = await db.getAll('progress');
      return JSON.stringify({ app: 'greek', version: 1, exportedAt: new Date().toISOString(), cards }, null, 2);
    },
    async importJSON(json) {
      let data: { app?: unknown; cards?: unknown };
      try {
        data = JSON.parse(json);
      } catch {
        throw new Error('Файл не является JSON');
      }
      if (!data || data.app !== 'greek' || !Array.isArray(data.cards) || !data.cards.every(isCardState)) {
        throw new Error('Неверный формат файла прогресса');
      }
      const cards = data.cards as CardState[];
      const tx = db.transaction('progress', 'readwrite');
      await Promise.all([
        tx.store.clear(),
        ...cards.map((c) => tx.store.put(c, progressKey(c.wordId, c.direction))),
        tx.done,
      ]);
      return cards.length;
    },
    async getCache<T>(key: string) {
      return (await db.get('cache', key)) as T | undefined;
    },
    async setCache(key, value) {
      await db.put('cache', value, key);
    },
  };
}
```

```ts
import { stripAccents } from './answer';

const MAP: Record<string, string> = {
  α: 'a', β: 'v', γ: 'g', δ: 'd', ε: 'e', ζ: 'z', η: 'i', θ: 'th', ι: 'i', κ: 'k', λ: 'l', μ: 'm',
  ν: 'n', ξ: 'x', ο: 'o', π: 'p', ρ: 'r', σ: 's', ς: 's', τ: 't', υ: 'y', φ: 'f', χ: 'ch', ψ: 'ps', ω: 'o',
};

export function transliterate(el: string): string {
  return [...stripAccents(el.toLocaleLowerCase('el'))]
    .map((c) => MAP[c] ?? c)
    .join('')
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '');
}

export function makeId(el: string, existing: Set<string>): string {
  const base = transliterate(el) || 'word';
  if (!existing.has(base)) return base;
  let i = 2;
  while (existing.has(`${base}-${i}`)) i++;
  return `${base}-${i}`;
}
```

`src/lib/validate.ts`:

```ts
import type { Conj, Word } from './types';
import { stripAccents } from './answer';

export const CONJ_VALUES: Conj[] = ['A', 'B1', 'B2', '-ομαι', 'irregular'];

export const BASE_TAGS = [
  'повседневное', 'движение', 'еда', 'общение', 'учёба', 'работа', 'дом',
  'покупки', 'чувства', 'здоровье', 'мышление', 'отношения', 'путешествия', 'действия',
];

const GREEK = /[Ͱ-Ͽἀ-῿]/;
const ISO = /^\d{4}-\d{2}-\d{2}$/;
const vowelGroups = (s: string) => (stripAccents(s.toLocaleLowerCase('el')).match(/[αεηιουω]+/g) ?? []).length;
const hasAccent = (s: string) => stripAccents(s) !== s;
const blank = (s: unknown) => typeof s !== 'string' || !s.trim();

export function validateWord(w: Word): string[] {
  if (!w || typeof w !== 'object') return ['запись не является объектом'];
  const at = w.el || w.id || '?';
  const e: string[] = [];
  if (!/^[a-z0-9-]+$/.test(w.id ?? '')) e.push(`${at}: некорректный id`);
  if (blank(w.el) || !GREEK.test(w.el)) e.push(`${at}: нет греческого слова`);
  else if (vowelGroups(w.el) > 1 && !hasAccent(w.el)) e.push(`${at}: нет ударения`);
  if (blank(w.ru)) e.push(`${at}: нет перевода`);
  if (w.conj !== undefined && !CONJ_VALUES.includes(w.conj)) e.push(`${at}: неизвестное спряжение ${w.conj}`);
  if (!Array.isArray(w.tags) || w.tags.some(blank)) e.push(`${at}: некорректные теги`);
  if (w.source !== 'base' && w.source !== 'user') e.push(`${at}: некорректный source`);
  if (w.source === 'base') {
    if (w.addedBy !== null) e.push(`${at}: у базового слова addedBy должен быть null`);
    if (blank(w.forms?.aorist) || blank(w.forms?.future)) e.push(`${at}: нет форм`);
    if (!w.conj) e.push(`${at}: нет спряжения`);
    if (blank(w.example?.el) || blank(w.example?.ru)) e.push(`${at}: нет примера`);
    if (!w.tags?.length || w.tags.some((t) => !BASE_TAGS.includes(t))) e.push(`${at}: теги вне списка`);
  }
  if (w.source === 'user' && blank(w.addedBy)) e.push(`${at}: нет автора`);
  if (!ISO.test(w.addedAt ?? '')) e.push(`${at}: некорректная дата`);
  return e;
}

export function validateWords(ws: Word[]): string[] {
  const e = ws.flatMap(validateWord);
  const ids = new Set<string>();
  const els = new Set<string>();
  for (const w of ws) {
    if (ids.has(w.id)) e.push(`дубликат id ${w.id}`);
    ids.add(w.id);
    const k = stripAccents((w.el ?? '').toLocaleLowerCase('el'));
    if (els.has(k)) e.push(`дубликат слова ${w.el}`);
    els.add(k);
  }
  return e;
}
```

```ts
import type { RepoConfig } from './config';
import type { Word, WordChange } from './types';
import { makeId } from './wordId';

export interface DictionarySnapshot { words: Word[]; sha: string | null; origin: 'remote' | 'cache' | 'bundled' }

export type DictionaryErrorKind = 'auth' | 'network' | 'conflict' | 'not-configured' | 'other';

export class DictionaryError extends Error {
  constructor(public kind: DictionaryErrorKind, message: string) {
    super(message);
    this.name = 'DictionaryError';
  }
}

export function encodeBase64Utf8(text: string): string {
  const bytes = new TextEncoder().encode(text);
  let bin = '';
  for (let i = 0; i < bytes.length; i += 0x8000) bin += String.fromCharCode(...bytes.subarray(i, i + 0x8000));
  return btoa(bin);
}

export function decodeBase64Utf8(b64: string): string {
  const bin = atob(b64.replace(/\s/g, ''));
  return new TextDecoder().decode(Uint8Array.from(bin, (c) => c.charCodeAt(0)));
}

export function applyChange(words: Word[], change: WordChange): Word[] {
  switch (change.type) {
    case 'add': {
      const ids = new Set(words.map((w) => w.id));
      const id = ids.has(change.word.id) ? makeId(change.word.el, ids) : change.word.id;
      return [...words, { ...change.word, id }];
    }
    case 'update':
      if (!words.some((w) => w.id === change.word.id)) {
        throw new DictionaryError('other', `Слово «${change.word.el}» не найдено — возможно, его удалили`);
      }
      return words.map((w) => (w.id === change.word.id ? change.word : w));
    case 'delete':
      return words.filter((w) => w.id !== change.id);
  }
}

export function commitMessage(change: WordChange, author: string): string {
  const label = change.type === 'delete' ? change.el : change.word.el;
  return `words: ${change.type} ${label} (by ${author || 'unknown'})`;
}

export interface RepoDeps {
  fetch: typeof fetch;
  cache: { get(): Promise<DictionarySnapshot | undefined>; set(s: DictionarySnapshot): Promise<void> };
  bundled(): Promise<Word[]>;
}

export interface DictionaryRepo {
  load(token?: string): Promise<DictionarySnapshot>;
  commit(change: WordChange, token: string, author: string): Promise<DictionarySnapshot>;
}

const MAX_ATTEMPTS = 3;

export function createDictionaryRepo(cfg: RepoConfig | null, deps: RepoDeps): DictionaryRepo {
  const url = cfg ? `https://api.github.com/repos/${cfg.owner}/${cfg.repo}/contents/${cfg.path}` : '';

  function headers(token?: string): Record<string, string> {
    const h: Record<string, string> = { Accept: 'application/vnd.github+json', 'X-GitHub-Api-Version': '2022-11-28' };
    if (token) h.Authorization = `Bearer ${token}`;
    return h;
  }

  async function request(input: string, init: RequestInit): Promise<Response> {
    try {
      return await deps.fetch(input, init);
    } catch {
      throw new DictionaryError('network', 'Нет соединения с GitHub');
    }
  }

  function failFor(res: Response): DictionaryError {
    if (res.status === 401 || res.status === 403) return new DictionaryError('auth', 'GitHub отклонил запрос — проверьте токен');
    if (res.status === 409 || res.status === 422) return new DictionaryError('conflict', 'Словарь изменился во время сохранения — попробуйте ещё раз');
    return new DictionaryError('other', `GitHub ответил ошибкой ${res.status}`);
  }

  async function fetchRemote(token?: string): Promise<DictionarySnapshot> {
    if (!cfg) throw new DictionaryError('not-configured', 'Репозиторий GitHub не определён');
    const res = await request(`${url}?ref=${cfg.branch}`, { headers: headers(token), cache: 'no-store' });
    if (!res.ok) throw failFor(res);
    const body = (await res.json()) as { content: string; sha: string };
    const words = JSON.parse(decodeBase64Utf8(body.content)) as Word[];
    if (!Array.isArray(words)) throw new DictionaryError('other', 'Файл словаря повреждён');
    return { words, sha: body.sha, origin: 'remote' };
  }

  return {
    async load(token) {
      try {
        const snap = await fetchRemote(token);
        await deps.cache.set(snap);
        return snap;
      } catch {
        const cached = await deps.cache.get().catch(() => undefined);
        if (cached) return { ...cached, origin: 'cache' };
        return { words: await deps.bundled(), sha: null, origin: 'bundled' };
      }
    },

    async commit(change, token, author) {
      if (!token) throw new DictionaryError('auth', 'Не задан GitHub-токен');
      let lastErr = new DictionaryError('conflict', 'Словарь изменился во время сохранения — попробуйте ещё раз');
      for (let attempt = 0; attempt < MAX_ATTEMPTS; attempt++) {
        const current = await fetchRemote(token);
        const words = applyChange(current.words, change);
        const res = await request(url, {
          method: 'PUT',
          headers: { ...headers(token), 'Content-Type': 'application/json' },
          body: JSON.stringify({
            message: commitMessage(change, author),
            content: encodeBase64Utf8(JSON.stringify(words, null, 2) + '\n'),
            sha: current.sha,
            branch: cfg!.branch,
          }),
        });
        if (res.ok) {
          const body = (await res.json()) as { content: { sha: string } };
          const snap: DictionarySnapshot = { words, sha: body.content.sha, origin: 'remote' };
          await deps.cache.set(snap);
          return snap;
        }
        lastErr = failFor(res);
        if (lastErr.kind !== 'conflict') throw lastErr;
      }
      throw lastErr;
    },
  };
}
```

```ts
import type { Direction, Grade, ProgressMap, Word, WordChange } from './types';
import { progressKey } from './types';
import { emptyFilter, type WordFilter } from './filters';
import { incNewSeen, loadSettings, newSeenToday, saveSettings, type Settings } from './settings';
import { newCard, schedule } from './srs';
import { todayISO } from './date';
import { applyChange, createDictionaryRepo, DictionaryError, type DictionarySnapshot } from './dictionaryRepo';
import { openProgressStore, type ProgressStore } from './progressStore';
import { resolveRepoConfig } from './config';
import { enqueuePending, flushPending, loadPending } from './pendingQueue';

export type Tab = 'learn' | 'dictionary' | 'add' | 'settings';

export const app = $state({
  ready: false,
  words: [] as Word[],
  origin: 'bundled' as DictionarySnapshot['origin'],
  progress: {} as ProgressMap,
  settings: loadSettings(),
  direction: 'el-ru' as Direction,
  filter: emptyFilter(),
  studyFilter: null as WordFilter | null,
  tab: 'learn' as Tab,
  toast: null as string | null,
  pending: loadPending().length,
});

export const repoConfig = resolveRepoConfig(location, import.meta.env);

let storePromise: Promise<ProgressStore> | null = null;
export function store(): Promise<ProgressStore> {
  return (storePromise ??= openProgressStore());
}

const repo = createDictionaryRepo(repoConfig, {
  fetch: (input, init) => fetch(input, init),
  cache: {
    get: async () => (await store()).getCache<DictionarySnapshot>('dictionary'),
    set: async (s) => (await store()).setCache('dictionary', s),
  },
  bundled: async () => (await import('../../data/words.json')).default as Word[],
});

let toastTimer: ReturnType<typeof setTimeout> | undefined;
export function toast(msg: string): void {
  app.toast = msg;
  clearTimeout(toastTimer);
  toastTimer = setTimeout(() => (app.toast = null), 3500);
}

function reapplyPending(words: Word[]): Word[] {
  return loadPending().reduce((ws, p) => {
    try {
      return applyChange(ws, p.change);
    } catch {
      return ws;
    }
  }, words);
}

export async function initApp(): Promise<void> {
  app.progress = await (await store()).getAll();
  await refreshDictionary(false);
  app.ready = true;
  if (navigator.onLine) void syncPending();
}

export async function refreshDictionary(notify = true): Promise<void> {
  const snap = await repo.load(app.settings.githubToken || undefined);
  app.words = reapplyPending(snap.words);
  app.origin = snap.origin;
  if (notify) {
    toast(snap.origin === 'remote'
      ? `Словарь обновлён: ${snap.words.length} слов`
      : 'Нет связи с GitHub — показана сохранённая копия');
  }
}

export async function gradeCard(word: Word, direction: Direction, grade: Grade): Promise<void> {
  const key = progressKey(word.id, direction);
  const today = todayISO();
  const prev = app.progress[key];
  // $state.snapshot: IndexedDB не умеет клонировать Svelte-прокси
  const next = schedule(prev ? $state.snapshot(prev) : newCard(word.id, direction, today), grade, today);
  app.progress[key] = next;
  if (!prev) incNewSeen(direction, today);
  await (await store()).put(next);
}

export function newLimit(direction: Direction): number {
  return Math.max(0, app.settings.newPerDay - newSeenToday(direction, todayISO()));
}

export function updateSettings(s: Settings): void {
  app.settings = s;
  saveSettings(s);
}

async function forgetProgress(id: string): Promise<void> {
  delete app.progress[progressKey(id, 'el-ru')];
  delete app.progress[progressKey(id, 'ru-el')];
  await (await store()).deleteWord(id);
}

async function queueChange(change: WordChange, author: string): Promise<boolean> {
  enqueuePending({ change, author });
  app.pending = loadPending().length;
  try {
    app.words = applyChange($state.snapshot(app.words), change);
  } catch {
    /* слово уже удалено — нечего применять локально */
  }
  if (change.type === 'delete') await forgetProgress(change.id);
  toast('Нет сети — сохраню, когда появится связь');
  return true;
}

export async function saveWordChange(change: WordChange): Promise<boolean> {
  const { githubToken, name } = app.settings;
  if (!repoConfig) {
    toast('Репозиторий GitHub не определён');
    return false;
  }
  if (!githubToken || !name) {
    toast('Укажите имя и токен в настройках');
    return false;
  }
  if (!navigator.onLine) return queueChange(change, name);
  try {
    const snap = await repo.commit(change, githubToken, name);
    app.words = reapplyPending(snap.words);
    app.origin = 'remote';
    if (change.type === 'delete') await forgetProgress(change.id);
    toast('Сохранено');
    return true;
  } catch (e) {
    if (e instanceof DictionaryError && e.kind === 'network') return queueChange(change, name);
    toast(e instanceof Error ? e.message : 'Не удалось сохранить');
    return false;
  }
}

export async function syncPending(): Promise<void> {
  if (!app.pending || !repoConfig || !app.settings.githubToken) return;
  const r = await flushPending(async (item) => {
    try {
      const snap = await repo.commit(item.change, app.settings.githubToken, item.author);
      app.words = snap.words;
      app.origin = 'remote';
    } catch (e) {
      // Неустранимая ошибка (например, правка удалённого слова) — выбрасываем изменение, чтобы не блокировать очередь
      if (e instanceof DictionaryError && e.kind === 'other') {
        toast(`Изменение отброшено: ${e.message}`);
        return;
      }
      throw e;
    }
  });
  app.pending = r.remaining;
  app.words = reapplyPending($state.snapshot(app.words));
  if (r.sent) toast(`Отправлено изменений: ${r.sent}`);
  if (r.error && !(r.error instanceof DictionaryError && r.error.kind === 'network')) {
    toast(r.error instanceof Error ? r.error.message : 'Не удалось отправить изменения');
  }
}
```

```svelte
  let tags = $state<string[]>(edit ? [...edit.tags] : []);

  let exEl = $state(edit?.example?.el ?? '');
  let exRu = $state(edit?.example?.ru ?? '');
  let errors = $state<string[]>([]);
  let saving = $state(false);

  const key = (s: string) => stripAccents(s.trim().toLocaleLowerCase('el'));

  const configured = $derived(!!app.settings.name && !!app.settings.githubToken);

  function toggleTag(t: string) {
    tags = tags.includes(t) ? tags.filter((x) => x !== t) : [...tags, t];
  }
  function addTag() {
    const t = newTag.trim().toLocaleLowerCase('ru');
    if (t && !tags.includes(t)) tags = [...tags, t];
    newTag = '';
  }

  function build(): Word {
    const w: Word = {
      id: edit?.id ?? makeId(el, new Set(app.words.map((x) => x.id))),
      el: el.trim(),
      ru: ru.trim(),
      tags: [...tags],
      source: edit?.source ?? 'user',
      addedBy: edit ? edit.addedBy : app.settings.name,
      addedAt: edit?.addedAt ?? todayISO(),
    };
    const forms: NonNullable<Word['forms']> = {};
    if (aorist.trim()) forms.aorist = aorist.trim();
    if (future.trim()) forms.future = future.trim();
    if (forms.aorist || forms.future) w.forms = forms;
    if (conj) w.conj = conj;
    if (exEl.trim() && exRu.trim()) w.example = { el: exEl.trim(), ru: exRu.trim() };
```

````markdown
Чтобы локально работала запись в словарь, создайте `.env.local`:

```
VITE_GH_OWNER=<owner>
VITE_GH_REPO=<repo>
```

## Деплой

Push в `main` → GitHub Actions (`.github/workflows/deploy.yml`) прогоняет тесты, собирает и публикует на Pages. В настройках репозитория: Settings → Pages → Source: **GitHub Actions**.
````

- [ ] **Step 5: Публикация (только после подтверждения пользователя — действие внешнее)**

Спросить пользователя про имя репозитория (по умолчанию `greek`) и подтверждение публикации. Затем:

```bash
gh repo create greek --public --source . --push
gh api -X POST repos/{owner}/greek/pages -f build_type=workflow
gh run watch
```

Expected: workflow зелёный; `https://<owner>.github.io/greek/` открывается.

- [ ] **Step 6: Сквозная проверка на проде**

- Открыть Pages-URL с телефона, установить на экран «Домой».
- В настройках указать имя и токен; добавить слово (например, «κολυμπάω — плавать», тема «движение») → тост «Сохранено», в репо появился коммит `words: add κολυμπάω (by …)`.
- На втором устройстве (или в другом браузере): Настройки → «Обновить словарь» → новое слово видно, фильтр «Источник: добавлено» и «Кто добавил» его находят.
- Отредактировать и удалить это слово — коммиты `words: update …`, `words: delete …`.
- Включить авиарежим, добавить слово → «Нет сети — сохраню…»; выключить авиарежим → «Отправлено изменений: 1».
