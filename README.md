# Ελληνικά — глаголы

PWA для изучения греческих глаголов (A2) в обоих направлениях: карточки с интервальным повторением и режим ввода. Общий словарь — `data/words.json` в этом репозитории; прогресс хранится на каждом устройстве.

## Установка на телефон

Откройте `https://<owner>.github.io/<repo>/` → «Поделиться» → «На экран Домой» (iOS) или «Установить приложение» (Android).

## Добавление слов

В приложении: Настройки → имя и GitHub-токен (fine-grained, только этот репозиторий, Contents: Read and write). Каждое добавленное слово — коммит в `data/words.json`. При создании токена в Expiration выберите максимальный срок: после истечения токен перестанет работать (приложение покажет предупреждение, чтение словаря продолжит работать без токена).

Новые слова приходят через API, приложение не пересобирается. Безопасность: не размещайте сторонние сайты на других GitHub Pages этого аккаунта — origin общий (`<owner>.github.io`), а токен хранится в localStorage.

## Слова из Telegram

Бот раз в час (GitHub Actions, `telegram-import.yml`) читает новые сообщения группы, через OpenRouter извлекает слова и добавляет их в `data/words.json` с автором «Telegram», затем отвечает в группу списком добавленного. Неверно распознанное слово правится или удаляется в приложении.

Настройка:
1. @BotFather → `/newbot`, сохранить токен. Затем `/setprivacy` → выбрать бота → **Disable** (иначе бот не видит обычные сообщения).
2. Добавить бота в группу.
3. Settings → Secrets and variables → Actions → **Secrets**: `TELEGRAM_BOT_TOKEN`, `OPENROUTER_API_KEY` (openrouter.ai → Keys). **Variables** (необязательно): `OPENROUTER_MODEL`, по умолчанию `anthropic/claude-haiku-5.5`.
4. Написать в группу любое сообщение, запустить Actions → Telegram import → Run workflow. В логе будет `id` группы (отрицательное число) — сохранить его в секрет `TELEGRAM_CHAT_ID`.
5. Написать в группу слово (например `το νερό - вода`) и снова запустить workflow — бот ответит «📚 Добавлено 1».

Ограничения: бот видит только сообщения после добавления в группу; Telegram хранит необработанные сообщения 24 часа — если Actions не запускались дольше, эти слова пропадут. GitHub отключает cron-workflow после 60 дней без коммитов в репозитории — тогда включить его снова на вкладке Actions.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # unit-тесты + валидация словаря
npm run check      # svelte-check
npm run build
```

Чтобы локально работала запись в словарь, создайте `.env.local`:

```
VITE_GH_OWNER=<owner>
VITE_GH_REPO=<repo>
```

## Деплой

Push в `main` → GitHub Actions (`.github/workflows/deploy.yml`) прогоняет тесты, собирает и публикует на Pages. В настройках репозитория: Settings → Pages → Source: **GitHub Actions**.
